# Employee Attrition Analysis and Prediction using Data Analytics and AI

## Project Overview
This project analyzes employee information to understand factors related to employee attrition and builds a machine-learning model and interactive Web Application to predict whether an employee may leave.

The project demonstrates a complete data analytics & AI workflow:
- Data collection using a synthetic educational dataset
- Data cleaning & preprocessing
- Exploratory Data Analysis (EDA)
- Interactive Data Visualization Dashboard
- Machine Learning classification (Logistic Regression & Random Forest)
- Real-time AI Risk Prediction Web Application
- Model evaluation & feature importance analysis
- Data-driven HR business recommendations

## Objectives
1. Clean and prepare employee data.
2. Explore patterns related to employee attrition.
3. Visualize important workforce trends.
4. Build classification models (Logistic Regression & Random Forest).
5. Provide real-time web-based AI predictions and HR recommendations.

## Dataset
The dataset contains 1,000 synthetic employee records with variables such as:
- Age
- Department
- Job Level
- Monthly Income
- Years at Company
- Job Satisfaction
- Work-Life Balance
- Overtime
- Distance from Home (km)
- Training Hours
- Number of Companies Worked
- Attrition (Yes / No)

## Tools and Technologies
- **Python 3**
- **Flask** (Web Application & REST API)
- **Pandas** & **NumPy** (Data Processing)
- **Matplotlib** & **Chart.js** (Visualizations)
- **Scikit-learn** (Machine Learning Pipeline)
- **HTML5 / CSS3 / JavaScript** (Glassmorphic UI Dashboard)

## How to Run

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Run the Interactive Web Application
```bash
python app.py
```
Open your browser and navigate to `http://localhost:5000` to view the interactive dashboard, test AI predictions, search employee dataset records, and retrain models.

### 3. Run the CLI Analytics & Chart Generator
```bash
python employee_attrition_analysis.py
```
The static charts and analysis summary text will be saved inside `results/`.
